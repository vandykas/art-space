# Art Space App

A simple Android application built with Kotlin and Jetpack Compose as 
part of the Android Basics with Compose course. The app displays a 
collection of picture that users can browse using Previous and 
Next navigation buttons.

## Features

- Browse a collection of picture
- View a short description for each picture
- Navigate through the collection using Previous and Next buttons
